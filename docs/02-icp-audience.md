# ICP & Target Audience

## Ideal Customer Profile (ICP)

### Primary ICP: "Le Dirigeant de TPE de Nettoyage"

| Attribute | Detail |
|---|---|
| **Role** | Owner / CEO / Gérant of a cleaning company |
| **Company size** | 5–50 employees (TPE/PME) |
| **Revenue** | EUR 200K–2M annually |
| **Location** | France (all regions, but concentrated in Île-de-France, Auvergne-Rhône-Alpes, PACA, Occitanie) |
| **Tech maturity** | Low to medium — uses Excel, WhatsApp, paper, or basic software |
| **Pain points** | Regulatory compliance, recruitment, profitability per contract, digitization, competition |
| **Information needs** | Salary grids, software comparison, pricing benchmarks, legal updates, management tips |
| **Decision-making** | Autonomous for tools < EUR 500/month; consults network for larger investments |
| **Online behavior** | Searches Google for specific operational questions, reads LinkedIn, belongs to Facebook/WhatsApp pro groups |

### Secondary ICP: "Le Responsable d'Exploitation"

| Attribute | Detail |
|---|---|
| **Role** | Operations manager / Site supervisor / Team coordinator |
| **Company size** | 20–200 employees |
| **Responsibilities** | Scheduling, quality control, client relations, agent management |
| **Pain points** | Scheduling complexity, quality tracking, client complaints, HR management |
| **Information needs** | Planning templates, quality checklists, management methods, software features |
| **Decision influence** | Recommends tools; final decision by CEO |

### Tertiary ICP: "Le Prospect Acheteur de Services de Nettoyage"

| Attribute | Detail |
|---|---|
| **Role** | Facility manager, office manager, property manager, syndic de copropriété |
| **Needs** | Find a reliable cleaning provider for their building/office/property |
| **Online behavior** | Searches "société de nettoyage + [ville]", "devis nettoyage de bureaux" |
| **Value to us** | High-intent traffic for directory and lead generation (Réseau Propreté) |

## User Flows

### Flow 1: Guide Reader → SaaS Lead (Proprely)

```
Google Search "grille salaire agent nettoyage 2025"
  → Article: "Grille salariale propreté 2025 : guide complet"
    → Reads article (trust built)
      → CTA: "Télécharger la grille en PDF + calculateur heures"
        → Email capture (lead magnet)
          → Drip email (3-5 days)
            → CTA: "Découvrir Proprely — gestion simplifiée"
              → Landing Proprely.fr
                → Demo request
```

### Flow 2: Local Search → Directory → Quote Request (Réseau Propreté)

```
Google Search "société de nettoyage Lyon"
  → Local page: "Sociétés de nettoyage à Lyon"
    → Browses directory listings
      → CTA: "Obtenir 3 devis gratuits"
        → Form (intent captured)
          → Redirect to Réseau Propreté matching
```

### Flow 3: Tool User → Account → SaaS Lead

```
Direct or social "calculateur prix nettoyage"
  → Tool page: Calculateur
    → Uses tool (value experienced)
      → CTA: "Sauvegarder mon calcul / Recevoir par email"
        → Light registration (email + company)
          → Email with result + soft CTA Proprely
            → Proprely trial or demo
```

### Flow 4: Comparison Reader → Trial (Proprely)

```
Google/AI "meilleur logiciel pour société de nettoyage"
  → Comparison page: "Top 5 logiciels de nettoyage 2025"
    → Reads independent comparison (Proprely featured fairly)
      → CTA: "Tester Proprely gratuitement" (contextual)
        → Proprely.fr/signup
```
